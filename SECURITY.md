# Security policy

Aerie has not passed production acceptance.
See the [release policy](specs/release-policy.md) and the security ledgers for
[Falcon-512](specs/falcon-ledger.md) and
[Falcon-1024](specs/falcon-1024-ledger.md).

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/a16z/aerie/security/advisories/new)
through **Security → Report a vulnerability** on the repository.
If that is unavailable, email all three maintainers:

- Quang Dao <[qvd@andrew.cmu.edu](mailto:qvd@andrew.cmu.edu)>
- Alberto Centelles <[centelles.alberto@gmail.com](mailto:centelles.alberto@gmail.com)>
- Michael Zhu <[mzhu@a16z.com](mailto:mzhu@a16z.com)>

Include the affected commit, parameter set (Falcon-512 or Falcon-1024),
reproduction steps or a reproducer, expected and observed outcomes, and the
potential impact.

Keep sensitive details in the private reporting channel rather than public
issues or discussions.
